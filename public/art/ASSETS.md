# Art assets

Every asset here is original, first-party work made for this project. There is no stock imagery, no deity
imagery and no third-party media. Everything is served from 'self' (CSP `img-src 'self' data:`).

| Asset | Source / authorship | Notes |
| --- | --- | --- |
| `paper.svg` | Original, authored by the project team (DCO-32) | Procedural paper grain from an SVG `feTurbulence` filter, tileable 256x256. No raster source. |
| Tam quan still (`TamQuanStill`) | Original inline SVG, DCO-32 | Three-passage gate with layered curved tile roofs. Drawn from scratch. |
| Incense animation (`IncenseAnimation`) | Original inline SVG + CSS, DCO-32 | Stick, ember and smoke. Static under `prefers-reduced-motion`. |
| Night river frame (`NightRiver`) | Original inline SVG, DCO-32 | Moon, water and reflections. |
| Sky, Ground, Mist layers | Original inline SVG, DCO-32 | Colours come from `src/styles/tokens.css`. |

Inline components live in `src/components/temple/art/`. Add a row here for any new asset.
